Authentic row build AMC wins
Each covered fund takes its ltp from the freshest official AMC NAV — even when the snapshot is stale-dated — and previous_close from the official day before it, so change / percent_change are authentic on both sides. Unreachable source or uncovered fund → snapshot fallback.
Today's prices + merge NEPSE today-price
Official per-stock LTP / OHLCV from NEPSE, then the 14 OMF rows are appended (asset_type: open_ended_mutual_fund, no high/low/volume). OMF rows arrive already source-verified (step 3) — only verified numbers flow into the live files and LTP history.

LTP history shards live-close rule
Snapshot appended into data/ltp/monthly/*.json — but only after 16:00 NPT or while the market is open. Otherwise skipped (pre-open runs must not freeze a provisional noon price as the day's close).
OMF NAV history workers append-only
Same 6 AMC workers fill OMF points onto existing shard dates. Default = append new points only, never rewrites history. Runs only when LTP gained a new trading date this run — the hourly runs in between would only refetch identical NAVs. Shares one fetch cache with step 3, so AMCs are hit once per run.
  • Any fund failing (e.g. Nabil WAF) is skipped solo — market data unaffected
