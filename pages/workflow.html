Automation Map

Data Workflow Flowchart

A visual map of the scheduled jobs that keep YONEPSE updated: fast market refreshes during trading hours, one daily company/IPO refresh, and validation-only guardrails.

Market Cron

Every 30 minutes, Monday-Friday market window

Trigger

.github/workflows/scrape.yml

Runs from about 09:45 to 16:15 NPT.

Setup

Checkout repo, set up Python 3.9, install scraper dependencies and PyYAML.

Command python scripts/nepse-scraper/official_scraper.py --ltp-history live-close
Pulls Data
Live prices and market status Indices, summary, top stocks Notices, disclosures, exchange messages LTP monthly and daily shards Securities reference list
Validate

Checks JavaScript syntax, compiles Python, and runs project guardrails.

Commit

Commits changed files under data as YONEPSE Data Bot.

Daily IPO + Company Cron

Once daily at 09:45 NPT

Trigger

.github/workflows/scrape_ipo.yml

Runs once daily and can be started manually.

Company Command python scripts/nepse-scraper/official_scraper.py --financials --profiles --ltp-history skip
Daily Guard

data/company/run_metadata.json prevents financial/profile fetches from running more than once per Nepal day.

Company Data
Financial reports append to financials.json Profiles replace on source change in profiles.json Metadata updates when financials append
IPO + Action Commands upcoming_ipo_scraper.py proposed_dividend_scraper.py --mode latest sectors.py
Pulls Data
IPO upcoming and archive files Proposed dividend latest and history Sector code aliases
Commit

Commits data/company, IPO, dividend, and sector files as YONEPSE Ipo Bot.

Guardrails

Pull request or manual validation

Trigger

.github/workflows/guardrails.yml

Runs for pull requests or manual checks.

Setup

Checkout repo, set up Python 3.11 and Node 20.

Checks
node --check assets/js/script.js node --check assets/js/data.js python -m compileall scripts python scripts/validate_project.py
No Data Writes

This workflow does not scrape, commit, or push data.

Fast Loop Market data refreshes every 30 minutes during market hours.
Heavy Loop Financials and profiles get one daily scheduled check.
Financial Rule Historical financial reports are append-only.
Profile Rule Company profiles replace only when source data changes.
