Public NEPSE data workspace

YONEPSE keeps market data tidy, fast, and usable.

YONEPSE is a lightweight public dashboard and static JSON API for Nepal Stock Exchange data. It focuses on clean files, predictable endpoint paths, compact schemas, and a frontend that makes the market easier to scan without hiding the underlying data.

What YONEPSE Is For

The project gives developers and market watchers a simple way to inspect NEPSE data without needing a backend, token flow, or database. Static JSON files are published directly with the dashboard.

Data Principles

  • Keep canonical files grouped by domain.
  • Prefer compact public fields over raw upstream payloads.
  • Preserve enough legacy compatibility for migrations.

Automation

Market data refreshes through scheduled GitHub Actions during trading hours, while IPO, proposed dividend, sector, broker, and reference data are maintained by scraper workflows.

Guardrails

The repository checks JSON validity, OpenAPI YAML, compact data shapes, organized page paths, JavaScript syntax, and Python compilation before automated data updates are committed.

Use, Learn, Contribute

You can use the published data freely for dashboards, experiments, research, internal tools, or learning projects. If you build something useful, improve the scraper, or find a data issue, contributions are welcome.
