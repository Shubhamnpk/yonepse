# Support

Use the right GitHub path so the project stays easy to maintain:

- Bug in the dashboard: open a bug report.
- Wrong, stale, or missing JSON data: open a data issue.
- New endpoint or UI idea: open a feature request.
- Documentation problem: open a documentation issue.
- Security concern: follow `SECURITY.md`.

GitHub issues:

https://github.com/Shubhamnpk/yonepse/issues

This project is not affiliated with NEPSE, Merolagani, or ShareSansar. Market data should be treated as informational and independently verified before financial decisions.
