# Code of Conduct

YONEPSE should be a respectful and useful place for people working around Nepali market data, open data, and developer tooling.

## Expected Behavior

- Be kind and direct.
- Assume good intent, especially with new contributors.
- Keep criticism focused on code, data, docs, and behavior.
- Be patient with language differences and beginner questions.
- Credit data sources and contributors honestly.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Spam, market manipulation, or promotional abuse.
- Repeatedly derailing issues or pull requests.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or reject contributions that violate this code of conduct.

To report a problem, open a GitHub issue if it is safe to do so. For sensitive reports, use the private security/contact path described in `SECURITY.md`.
